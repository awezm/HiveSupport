# 🐝 HiveSupport 1.0 Alpha Installation Guide

## Welcome

Thank you for choosing **HiveSupport**!

HiveSupport is a modern Discord support and ticket management bot built with **TypeScript** and **discord.js**, designed to provide a clean, organized, and reliable support workflow for Discord communities.

This alpha release includes a complete ticket lifecycle, from ticket creation to automatic transcript archiving.

---

# ✨ Included Features

* Multi-category support panel
* Staff-only panel deployment
* Optional panel channel restriction
* Category-specific ticket intake forms
* Private ticket channels
* Duplicate ticket prevention
* Embedded ticket summaries
* Ticket close workflow
* Required close reason
* Optional staff notes
* Automatic transcript generation
* Transcript archive channel
* Configurable rotating bot presence
* Configuration-driven ticket system

---

# 📋 Requirements

Before installing HiveSupport, ensure you have:

* Node.js **20.x** or newer
* npm
* A Discord account
* A Discord server where you have Administrator permissions

---

# 🤖 Creating Your Discord Bot

HiveSupport does **not** include a pre-configured Discord application.

You'll need to create your own bot through the Discord Developer Portal.

## Create an Application

1. Visit the Discord Developer Portal:

https://discord.com/developers/applications

2. Click **New Application**

3. Give your application a name

4. Open the **Bot** page

5. Click **Add Bot**

6. Copy your **Bot Token**

---

## Enable Gateway Intents

Under the **Bot** page, enable:

* ✅ Server Members Intent

No additional privileged intents are required.

---

## Invite Your Bot

Open:

**OAuth2 → URL Generator**

Scopes:

* `bot`
* `applications.commands`

Recommended Bot Permissions:

* Administrator

Generate the invite URL and invite the bot to your Discord server.

# 📦 Installation

## 1. Download HiveSupport

Download the latest HiveSupport release and extract it to your preferred location.

---

## 2. Install Dependencies

Inside the project directory, run:

```bash
npm install
```

---

## 3. Configure Environment Variables

Rename:

```text
.env.example
```

to

```text
.env
```

Open the file and configure the required values.

Example:

```env
DISCORD_TOKEN=YOUR_BOT_TOKEN
CLIENT_ID=YOUR_APPLICATION_ID
GUILD_ID=YOUR_SERVER_ID

SUPPORT_ROLE_ID=YOUR_SUPPORT_ROLE_ID
TICKET_CATEGORY_ID=YOUR_TICKET_CATEGORY_ID

PANEL_CHANNEL_ID=OPTIONAL_PANEL_CHANNEL_ID
TRANSCRIPT_CHANNEL_ID=YOUR_TRANSCRIPT_CHANNEL_ID
```

---

# 🔧 Environment Variable Reference

| Variable              | Required | Description                                              |
| --------------------- | :------: | -------------------------------------------------------- |
| DISCORD_TOKEN         |     ✅    | Your Discord bot token                                   |
| CLIENT_ID             |     ✅    | Discord Application ID                                   |
| GUILD_ID              |     ✅    | Discord Server ID                                        |
| SUPPORT_ROLE_ID       |     ✅    | Role granted access to support tickets                   |
| TICKET_CATEGORY_ID    |     ✅    | Category where ticket channels are created               |
| PANEL_CHANNEL_ID      | Optional | Restrict the `/panel` command to a single channel        |
| TRANSCRIPT_CHANNEL_ID |     ✅    | Channel where ticket archives and transcripts are posted |

# ▶️ Starting HiveSupport

Development:

```bash
npm run dev
```

Production:

```bash
npm start
```

HiveSupport will automatically:

* Register slash commands
* Load events
* Load buttons
* Load modals
* Load configuration
* Start rotating presence
* Connect to Discord

---

# ✅ Verifying Installation

Once the bot is online:

1. Run:

```
/panel
```

2. Confirm the support panel appears.

3. Verify all four support buttons are visible:

* 🔧 Technical
* 💳 Billing
* 👤 Account
* 💬 General

4. Create a test ticket.

5. Verify:

* A private ticket channel is created.
* The embedded ticket summary appears.
* The configured support role has access.
* The ticket is placed inside the configured category.

6. Close the ticket.

7. Verify:

* A close reason is required.
* Optional staff notes may be entered.
* A transcript is generated.
* An archive embed is posted to the transcript channel.
* The `.txt` transcript file is attached.
* The ticket channel is automatically deleted.

---

# 👥 Staff Permissions

HiveSupport uses a configurable Discord role for support staff.

Members with the configured **SUPPORT_ROLE_ID** are granted access to ticket channels and support functionality.

Administrator permissions are still recommended during initial setup but are not required for day-to-day ticket management once configured correctly.

# ⚙️ Configuration

Several parts of HiveSupport are configuration-driven, allowing customization without editing core bot logic.

Current configurable systems include:

* Rotating bot presence
* Support categories
* Ticket intake questions
* Button labels
* Button styles
* Modal titles
* Embed colors
* Ticket channel prefixes
* Panel channel restriction
* Transcript archive channel
